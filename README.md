
# Zerodha Clone

A full-stack Zerodha Clone built using the MERN stack with features like holdings, positions, buy/sell, and charts.

## Tech Stack
- React.js, HTML, CSS, Bootstrap  
- Node.js, Express.js  
- MongoDB  
- Chart.js  

## Project Structure
- Zerodha/
- ├── backend/
- ├── frontend/
- └── dashboard/

## How to Run

### Clone Repo

```bash
git clone https://github.com/ayushmeen/Zerodha.git
```
```bash
cd Zerodha
```

### Backend
```bash
cd backend
```
```bash
npm install
```
```bash
npm start
```

### Frontend
```bash
cd frontend
```
```bash
npm install
```
```bash
npm start
```
### dashboard
```bash
cd dashboard
```
```bash
npm install
```
```bash
npm start
```
